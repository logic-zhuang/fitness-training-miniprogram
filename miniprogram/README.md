# 训练手记微信小程序

更新：2026-10-14。原生 WXML/WXSS/JavaScript，FastAPI 账号后端，纯业务规则从 React 项目生成复用。

## 打开当前开发项目

在微信开发者工具打开 `<worktree>\fastapi-全栈` 即可。根目录 `project.config.json` 的 `miniprogramRoot` 指向 `miniprogram/`；单独导入子目录也指向同一份代码。AppID 为 `wx86daa80eeb99998a`。桌面原目录是另一个副本，本轮不自动覆盖。

本机记录不依赖 Vite 或后端。修改共享业务后，在项目根目录运行 `bun run mini:build`，再点击编译。不要手改 `miniprogram/lib/core.js`。

## 当前流程

- 三个导航：今天 / 计划 / 我的。默认沿用星期安排，有草稿先继续，休息日可自由训练。
- 调整今天先准备动作、暂停计时，明确开始后再计时；本周换日仅改具体日期，有已调整标记和恢复入口，已有训练安排不重新分配。
- 逐动作记录，确认有效目标组后完成回顾、自动进入下一未完成动作；最后等待明确提交。待提交草稿重开保持冻结。
- 保存后总结显示目标达标、科学动作对比、实际部位分布、本周达标/次数；可后补照片、感受和备注。
- 我的包含训练日志与照片、个人动作库、目标与备份。日志按月份/日期组织，相册或拍照均可，照片保存持久文件并按账号隔离。
- 首页支持「今天休息」（休息日不计本周目标）、补练未练安排（选未练日期→今天练→原日期标已补练）、误触可放弃草稿；训练页可「沿用上次，填入全部空组」或「复制第 1 组到其余组」快速填重量次数。
- 照片分部位照片（填部位说明）与整体照片（选正面/侧面/背面，三角度不强制）；日志页按部位筛选对比、整体按角度分区按日期对比，编辑照片可改类型与角度。
- 训练已可靠写入本机后显示保存结果；云端同步失败保留原请求身份，可重试，照片失败不回滚训练。
- 微信登录接口和绑定入口已实现，真实身份联调尚未完成。旧网站账号先邮箱验证，再绑定微信；绑定失败和登录过期有重试入口。

## 账号连接与手机

开发地址配置在 `miniprogram/config.js`，当前为局域网联调地址 `http://<电脑局域网IP>:8001`（手机需与电脑同一网络；未提交到 Git）。正式环境需换成小程序后台备案的 HTTPS 域名。服务端配置 `WECHAT_APP_ID` 和 `WECHAT_APP_SECRET`；Secret 不进入小程序代码或仓库。正式环境地址与微信后台配置在上线阶段核对。

数据库先检查迁移版本。开发库为 `fitness_88a9_dev`；自动测试只能使用独立 `fitness_88a9_test`，测试夹具会清理测试账号。

## 检查范围

`bun test miniprogram-tests frontend/tests/fitness` 检查页面处理器、业务、存储和模拟请求；真实请求检查需单独设置 `FITNESS_TEST_SERVER`，并确认目标服务使用独立测试库。

官方 WXML/WXSS 编译和页面处理器检查不能替代微信开发者工具点击或手机输入、相册权限、后台恢复及网络验收。最新证据和待办见 [v3 实施与验收](../docs/FITNESS_V3_ACCEPTANCE.md)。正式发布、Agent、社交和小程序体重录入尚未交付。
