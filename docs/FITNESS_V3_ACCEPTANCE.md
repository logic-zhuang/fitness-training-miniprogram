# 健身记录 v3：实施状态与验收证据

更新：2026-10-07。目标为完整可用的小程序训练闭环，不能以自动检查通过替代最终落地。当前开发目录 `<worktree>\fastapi-全栈`，桌面原目录未覆盖。

## 本轮实际变更

- 首页显示本周日期覆盖标记，提供恢复默认安排。恢复只清理当前计划、当前周；已有草稿或训练的安排不能重新分配。日期选择和确认期间核对账号及模板，过期弹窗不写入新的账号。
- 调整今天先生成独立草稿并暂停计时；动作/组数准备完成后明确开始。继续待提交草稿保留 ready 阶段和冻结用时，动作完成草稿恢复不触发新的自动推进。
- 我的提供独立动作库管理。复用统一选择器，管理模式不要求建立训练；编辑、收藏和移除收进更多。
- 照片选图、上传和页面前台状态分离。系统相册触发 onHide 仍能完成持久保存与上传；后台上传完成后解除按钮锁定，旧账号操作不影响新账号。账号变化清除旧照片关联选择。
- 服务端 401 使账号显示重新验证入口。同一微信账号重新登录保留待同步内容；微信身份映射到其他内部账号时拒绝自动切换。已有网站账号绑定失败可重试，不因登录成功而丢失入口。
- 网页新增本周日期交换弹层与恢复入口，沿用同一 shared flow；继续待提交草稿保持冻结。
- 主说明、设计和小程序使用文档按 v3 更新，旧版记录单独保留。
- 网页照片页改为日期日志，支持普通健身照片、可选角度、训练关联与元数据修改。照片文件先写入 IndexedDB，再上传；失败保留原请求和文件，逐张重试、离线删除与账号隔离使用独立持久队列。旧照片库保留备份，新库用账号与照片复合身份。
- 网页保存后总结分区展示目标、动作对比、部位示意、本周进度和照片入口；感受与备注改为保存后的可选补充，只更新原记录。历史修改使用“保存记录修改”文案。
- 网页体验模式首次初始化可靠保存示例训练身份，修复刷新后照片关联到不存在的旧示例记录；日期标签合并实际部位与照片说明并去重。
- 小程序“保存补充内容”增加成功和失败反馈，失败保留输入供重试；原记录已删除时禁止旧总结重新生成记录。只更新感受和备注，保留原计时与记录身份。
- 复现并修正微信原生操作菜单项数超限：官方接口最多 6 项，原换日菜单和训练更多菜单均传入 7 项，动作位置还可能更多。现在本周日期使用七天 picker 与双方安排预览，训练操作使用分组弹层；移动到任意位置先预览顺序再确认，取消无改动，失败可重试。账号、模板、周范围变化和后台关闭过期操作。来源：[微信官方类型定义](https://github.com/wechat-miniprogram/api-typings/blob/master/types/wx/lib.wx.api.d.ts)。
- 小程序休息条和各阶段底部主操作改为同一固定容器，移除依赖固定按钮高度的休息定位；放弃草稿收入更多。待提交默认收起动作明细，保存按钮明确区分提交与历史修改。
- 自由训练支持本次组数与可选时长目标调整，不能减少已确认实际组；低于目标秒数保留组但不自动推进，周计划完成仍不授予自由训练。网页使用相同共享规则。
- 自动到达待提交页也检查已填未确认组；取消不提交，确认后保留原数据但不计入完成统计。小程序已确认且内容未变化时不重复弹窗；网页在实际提交时确认，提交页先展示缺项提示。
- 2026-10-09 保存后总结的部位示意改为自绘正背面 2D 肌肉图（`frontend/src/features/fitness/bodyMap.ts`，小程序经 `core.js` 复用）：17 块肌肉独立着色，按已确认有效组 1–3 组浅红、4 组及以上深红；内置动作有明确映射，自建动作按名称细分但不越出所属分类，未知分类只用文字列出。只标主部位，不标协同肌。小程序用 base64 SVG `<image>` 显示、按点击坐标命中；网页共用同一 SVG 与命中逻辑。未采用 3D：主包体积、低端机 WebGL 性能、模型授权和维护成本均不可控。

## 本轮网页实际操作

使用独立 Playwright 无界面体验会话，没有登录个人账号：320px 打开日期弹层，选择周五与周日并确认交换；首页两份安排正确互换、训练次数保持 2 次。430px 再打开管理并确认恢复，首页恢复周五背部、周日肩部。关闭弹层回到正常导航，无浏览器运行错误。

320px 页面宽度与文档宽度均为 320，弹层左右位于 16–304；430px 页面宽度与文档宽度均为 430，弹层左右位于 16–414。截图：[320px](../output/playwright/fitness-week-320.png)、[430px](../output/playwright/fitness-week-430.png)。证据仅覆盖网页日期弹层与首页变化，不扩展为全部网页或微信真机验收。
