## 使用哪份代码

当前开发目录为 `<worktree>\fastapi-全栈`。微信开发者工具打开根目录即可；`project.config.json` 自动从 `miniprogram/` 读取 `app.json`。也支持单独导入该子目录，两种方式用同一份代码。

“详情 → 基本信息 → 本地目录”可核对路径。`fastapi-全栈` 是旧副本，本轮不自动覆盖。若报根目录缺少 app.json，核对上述路径和 miniprogramRoot，重新打开项目再编译。本机训练不用启动网页或后端。

## 当前实现与剩余条件

小程序已实现今天/计划/我的、默认星期安排、本次调整、本周换日及恢复、动作库、逐动作推进、明确提交后总结、照片日期日志、本机保存及账号同步。代码验证范围见 [v3 记录](FITNESS_V3_ACCEPTANCE.md)，旧版记录保留在 [v2 记录](FITNESS_V2_ACCEPTANCE.md)。

本周日期在同一弹层选择两个星期并预览双方变化，确认后仅修改本周；动作更多按用途分组，移动先预览顺序再确认。休息条与主要按钮共用底部容器。自由训练可调整组数和每组目标秒数；不足秒数保留组但不自动推进。自动进入待提交时仍检查未确认组。上述处理器回归与官方编译已通过，实际微信弹层、滚动和手机键盘仍需验收。

微信登录和绑定接口已写入后端，小程序也有入口。实际登录仍需要服务端 Secret、有效微信 code、手机可访问的后端以及微信真实环境验证；模拟 code 检查不能证明真实身份已经联通。当前 config.js 的 127.0.0.1 是电脑开发地址。
